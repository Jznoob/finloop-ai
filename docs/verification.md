## 检索评测口径

- 8 篇演示文档，8 个相关查询，2 个无关查询。
- 相关查询：Recall@2 = 1.000、Precision@2 = 0.500、MRR@2 = 1.000。
- 无关查询：2 / 2 返回空结果。
- 强制制度载入不计入检索效果；精确率分母固定为 2。
- 自建小语料合成回归，不是独立真实金融基准，不能外推到真实检索性能。

## 浏览器人工验收

已在本地页面操作验证：

1. 创建任务后得到已保存结果，七个导航页面可切换。
2. 复核保存后表单锁定，已提交状态可重新读取。
3. 证据原文弹窗可打开并用 Escape 关闭，能看到指纹和固定制度标记。
4. 无关知识查询返回空结果，不强塞“相关证据”。
5. 实验室展示样本量、区间、策略差异与保存报告。
6. 记忆中的同内容旧条目折叠，整组禁用/恢复成功，未删除原数据。
7. 页面触发评测得到 18/18 报告。
8. 运行历史可以打开尝试日志，显示阶段、状态和消息。
9. 配置页显示本地模板、模拟模式与实际预算边界，不暴露密钥。
10. 桌面宽屏与 390 px 窄屏工作台/实验室做过视觉检查，窄屏无文档横向溢出。最后修正了末端流程节点宽度，并检查节点处于容器内。
11. 新版沉默激活输出“低负担阅读邀请”，包括主题、渠道和暂停接收选项，不再固定输出波动应对话术。

页面验收只涉及虚构数据与模拟渠道。少量带“浏览器验收记录”备注的复核和演示任务保留在本地数据库，不是实际客户或用户研究数据。

## 未验收与已知边界

- 未调用真实远程模型；已用模拟响应验证网关成功/失败分支。
- 未完成 Docker 构建验收，也未发布线上站点。
